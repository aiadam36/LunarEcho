# LunarEcho Origin

LunarEcho is not a project that started with this repository.

Its development dates back to **March 2025**, when it originally existed as a privately maintained Discord bot. Back then, its source code was closed and its development history was never properly documented.

The original project went through its own development process, long before becoming publicly available.

## Original Bot

The original LunarEcho Discord application was already established in 2025.

## New Beginning

When the decision was made to open-source LunarEcho, the repository was recreated rather than exposing the original private repository.

This allowed the project to receive:

- A clean Git history
- Better documentation and organization
- A publicly accessible codebase
- A fresh foundation for future development

As a result, the current repository does not contain the complete development history of LunarEcho.

Its first public commits represent the beginning of its open-source chapter, not the beginning of the project itself.
